# 0.4.0 可见窗口验收单

本文件供 Windows 用户在真实窗口中检查；本轮自动化只使用 Qt offscreen，以下项目均为 **NOT TESTED**，不能据此宣称视觉验收通过。

1. **字体搜索与预览 — NOT TESTED**：打开含译文的项目，选中文本框，在“样式”打开字体浏览器，搜索中英文字体；选择前后观察画布临时预览，取消后确认项目样式没有改变。
2. **收藏与最近使用 — NOT TESTED**：收藏一款字体，实际应用另一款；重启程序后检查收藏和最近列表。
3. **项目样式与继承 — NOT TESTED**：在 Project Styles 修改 speech 预设，确认未覆盖的框同步变化；设置单框覆盖，再改预设，确认单框覆盖仍有效。
4. **角色与批量应用 — NOT TESTED**：将文字框设为 narration，分别试当前页、批次和项目范围应用样式，检查目标及非目标框。
5. **Auto Fit 与溢出 — NOT TESTED**：在窄框输入较长中文，检查 warning/overflow、最小字号、换行标点；扩大框后检查状态恢复。再检查横排、竖排、100% 与导出图片。
6. **质量检查与定位 — NOT TESTED**：运行 Quality Check，双击缺译或溢出问题，检查页面和框被选中，修复后重新运行。
7. **撤销与重做 — NOT TESTED**：修改项目预设、角色、单框样式和批量替换字体，逐一 Ctrl+Z/Ctrl+Y 检查数据与画布。
8. **简单/高级模式 — NOT TESTED**：切换模式，检查右侧标签、菜单、可点击区域、缩放和窗口布局。
9. **缺失字体 — NOT TESTED**：使用另一台未安装项目字体的 Windows 机器打开项目，检查提示、替换、重新打开和导出。

记录每项 PASS/FAIL 与截图或日志路径；若失败，保留原项目副本和操作步骤。相似字体推荐只提供候选，需人工挑选。复杂竖排标点和字体字形应人工校对。
