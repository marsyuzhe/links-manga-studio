# Links Manga Workspace 可见窗口验收（视觉重构）

以下为用户在真实 Windows 窗口中的手动检查清单。本轮开发验证使用 Qt offscreen 截图和自动测试；真实窗口、手感及 DPI 检查为 **NOT TESTED**。

1. **启动**：解压便携 ZIP，保留 `runtime/` 与 EXE 在同一目录，双击 `LinksMangaWorkspace.exe`。确认标题、拖放区、新建项目、打开项目、打开 PDF 和最近项目可读可点。
2. **工作区**：打开一本漫画。检查左侧工具轨及页面/OCR/批次/项目标签、居中画布、右侧译文/样式/排版/原文/擦除标签；底部任务区默认折叠。
3. **页面与画布**：选中页仅显示窄蓝色指示；文件名在 Tooltip。切页、缩放、拖动画布、文本框选中手柄和右键菜单均可用。
4. **文字框**：点击 OCR 框；右侧显示原文与译文。输入译文后等待自动保存，按 Ctrl+Enter 执行擦除并回填。切换框后重新打开确认译文保留。
5. **字体浏览器**：在样式页搜索字体、切换项目/推荐/最近/收藏/全部，检查每款字体的译文预览；取消时不应修改项目样式。
6. **质量检查**：项目菜单运行检查，底部质量面板显示问题；双击问题应定位到页和文字框。状态栏警告入口应能重新打开结果。
7. **Focus Mode**：按 Tab，左侧工具轨、页面面板、右侧检查器和底部面板收起，顶部工具栏与画布保留；再次按 Tab 恢复。
8. **简洁/高级**：设置菜单切换模式。简洁模式不显示内部 UID、BBox 和复杂参数；高级模式可见高级标签。关闭重开后偏好应保留。
9. **窗口大小**：分别在 1366×768、1920×1080、2560×1440 检查画布可用、侧栏不遮挡画布；拖动分隔条、折叠侧栏后仍可编辑。
10. **DPI**：在实际拥有的 100%、125%、150%、200% 缩放环境下检查菜单、工具轨、画布文字框和点击位置；只记录真正执行过的值。
11. **对话框与语言**：检查导入确认、错误提示、设置、项目样式和字体浏览器的深色外观；切换中文/英文后查看标签是否截断。

每项填写 PASS、FAIL 或 NOT TESTED，并保留失败截图及 `logs/app.log`。开发截图在 `docs/ui_snapshots/`，这些截图由 Qt offscreen 生成，仅供布局自检。
