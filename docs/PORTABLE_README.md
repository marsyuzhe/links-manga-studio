# Links Manga Studio 0.6.0

Local-first manga OCR, translation, cleaning and typesetting studio for Windows.

Created by Links Tam.

Extract this entire folder and run LinksMangaWorkspace.exe. Keep runtime/ beside it. No Python installation is needed.

Read QUICK_START.md, USER_GUIDE.md or USER_GUIDE.zh-CN.md. Manual translation works without API keys. Optional translation uses services you configure yourself; LLM weights are not bundled.

Back up full .lmw projects and referenced sources before upgrading. Core OCR models are bundled.
