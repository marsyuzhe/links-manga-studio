# Public source asset audit

The public source tree contains only the generated multi-size application icon (`assets/icons/*.png`, `*.ico`) and UI screenshots in `docs/images/` and `docs/ui_snapshots/`. The icon is generated by `tools/build_icon.py`; the screenshots are generated by `tools/capture_ui_snapshots.py` from a synthetic panel and original text. No commercial comic panel, user image, PDF, project database, font file or model weight is intended to be tracked.

`tests/fixtures/synthetic.py` generates speech bubbles, Chinese/English OCR text, vertical text and multi-page PDFs on demand. The generator is source code; generated PDFs and pages stay in test temporary directories.

Before the first push, inspect `git status --short` and the staged file list. The current Git root is the **parent directory**, which contains unrelated untracked work. Publish only this application subtree through a dedicated repository chosen by the owner; do not run `git add .` at the parent root. The source `.gitignore` excludes `.lmw`, SQLite projects, downloaded models, fonts, caches, logs, builds and ZIPs.

The portable ZIP has a separate audit: it includes third-party binaries and OCR models, and its three OCR artifacts are confirmed by upstream model notice and SHA256 in `MODEL_LICENSES.md`. Original brand art, synthetic fixtures and screenshots are Apache-2.0; third-party binaries retain their own terms.

The original GitHub preview (1280 × 640) is drawn by tools/build_social_preview.py with the existing icon. No commercial manga, account details or private paths are used.
