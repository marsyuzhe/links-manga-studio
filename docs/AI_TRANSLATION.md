# AI 翻译 / Translation Center — v0.6.0

人工翻译仍可在漫画工作区右侧直接输入，不需要账号、服务配置或 API。AI 翻译通过主窗口内部的独立“翻译中心”完成。

## 1. 入口与范围

完成 OCR 后点击顶部 **翻译**：进入翻译中心，默认当前页。下拉菜单支持当前文本、当前页、所选页面、批次、全项目。所选页面填写 `1,3,5-10`。
翻译中心只有三个标签：**翻译任务 / 历史任务 / 翻译服务**。普通“设置 → 翻译”只保留默认服务、默认语言及管理入口。

## 2. 添加服务

打开 **翻译中心 → 翻译服务 → 添加服务**，选择云端 API、Ollama 或本地 OpenAI-compatible。

| 类型 | 地址示例 | 模型 |
|---|---|---|
| 云端 OpenAI-compatible | `https://api.openai.com/v1` | 服务实际支持的模型 ID |
| Ollama | `http://localhost:11434` | 本机已安装模型名 |
| LM Studio / 本地 OpenAI-compatible | `http://localhost:1234/v1` | 本地服务提供的模型 ID |

服务配置填写名称、地址、模型；云端填写 API Key。高级区管理温度、超时、并发、重试。不要把 `/chat/completions` 或 `/api/chat` 添加到地址末尾，应用会追加协议路径。
“检测服务 / 测试连接”只请求模型列表，“刷新模型”列出已有模型，不下载或安装模型。未检测不会显示已连接。
Ollama / LM Studio 等服务由用户自行安装并启动。应用不捆绑大型 LLM、不安装外部服务。Local 只接受 localhost / 回环 IP，绕过环境代理。远程服务器请使用云端配置。
当前是 Chat Completions 协议，不支持 Responses-only 或 Gemini / Claude 专用协议。

## 3. 项目术语库

**翻译 → 术语库**打开独立项目术语库。术语包括原文、固定译名、分类、备注；分类支持人物 / 地点 / 组织 / 物品 / 技能 / 其他。
使用“添加术语”、双击编辑、原文 / 译文 / 备注搜索、类型筛选和名称 / 最近修改排序。固定译法冲突明确标记。
更多菜单提供 CSV 导入 / 导出、删除、撤销 / 重做。CSV 字段：`source,target,category,note`；分类值：`character,place,organization,item,skill,other`。导入报告成功、跳过、冲突。重复或空项跳过；缺少必要列会报错。导出对电子表格公式起始符作中和处理。
人物标签是人物列表与详情：姓名、固定译名、身份、说话风格、备注。修改保存到 SQLite；切换人物前保存备注。CSV 一次导入形成同一 Undo 组。
任务运行时请先暂停并等待当前请求结束，再编辑术语。术语与人物通过 JSON 数据传给模型，仍需人工检查模型是否遵守；不会把术语文本变成系统指令。

## 4. 开始与审核

任务页显示范围、当前服务 / 模型、目标语言、风格、上下文、术语和人物开关。摘要和隐私提示固定在底栏。
点击“开始翻译”先检测服务、模型和认证，再预检实际文本数量、人工修改 / 已审核保护和术语冲突。默认保护人工与已审核内容，默认跳过已有 AI 初译。高级任务选项可显式覆盖保护内容，开始前显示警告。
云端预检开始确认表示同意向配置的第三方发送 OCR 文本、上下文和规则。确认与配置 ID、类型、地址绑定；地址变化需重新确认。API Key 留在 Windows Credential Manager，不写项目 / 日志 / 导出，也没有明文后备。
目标语言用于提示；现有单一译文槽仍为 `zh_CN`，没有多语言并行译文。
“查看 AI 初译”返回漫画并筛选 AI Draft。人工编辑后可标记已审核；`Ctrl+Enter` 擦除并回填，Text UID 不变。AI 翻译按页 Undo。

## 5. 进度、Token 与任务

翻译中心显示已处理页 / 当前 Page UID、完成文本数、成功、失败、请求、用时、Input / Output / Total、费用未配置。
统计来自持久任务和请求记录。服务缺少 usage 时显示“服务未提供统计”，部分 usage 标注“部分统计”，不猜 Token / 费用 / ETA。请求数包括返回的 HTTP 重试次数；详细信息默认折叠，不显示原始正文或密钥。
“暂停”停止新派发，已发出的请求允许完成并提交。“继续”只处理剩余项；“取消任务”保留完成结果，终止后续派发。“重试失败项”不重复成功页；失败行可单页重试或双击定位。
退出时等待当前请求保存后关闭，任务状态持久化；意外退出通过既有任务恢复机制处理。重开后不自动发送内容。
新任务快照保存项目规则和模型名；术语与端点在继续时读取当前配置，改变端点需要重新确认。HTTP 中断恢复不保证服务端 exactly-once，服务端已处理的请求可能在恢复后再次计费。
429 / 5xx / 超时 / 连接或 HTTP JSON 损坏有受控退避；不合法的 Text UID 输出拒绝整页。单页失败不阻止其他页。

## 6. 项目兼容

产品版本仍为 **0.6.0**。Schema 6 在既有 Schema 5 上增加术语分类 / 修改时间、人物备注和安全请求记录，迁移前备份。Page UID / Text UID / DOCX 协议不变，旧人工译文保留。
项目升级后不要交给旧版程序写入；回退使用完整升级前项目副本或备份及对应 project.json。旧 0.5.0 和前一版 0.6.0 包保留。
DOCX 回导仍视为人工编辑；未审核 AI 草稿是质量警告。

## 7. 验证边界

自动验收使用合成项目、Fake Provider 和回环 Mock HTTP，没有调用真实付费接口。Qt offscreen 不是可见 Windows UX / 实际 DPI 验收。
真实付费 API、真实本地模型、可见 Windows UX：**NOT TESTED / USER ACCEPTANCE REQUIRED**。按 [最终用户验收](FINAL_USER_ACCEPTANCE_0.6.0.zh-CN.md) 自行测试，不向 Codex 提供密钥。

## FAQ

- 没有 API Key：可直接人工输入；本地模型需要用户自己的已运行服务。
- 无法连接本地模型：启动服务，再检测地址 / 模型。
- Token 不可用：服务未返回可靠 usage，程序不会填 0。
- 人工译文没被覆盖：默认保护，需显式启用覆盖并确认。
- 术语库编辑未进入：先暂停正在运行的任务，等待当前请求结束。
