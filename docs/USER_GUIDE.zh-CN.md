# Links Manga Studio 0.6.0 用户指南

适用：Windows 10/11 x64。界面可在设置中切换简体中文或英文；下面使用中文名称，括号中给出常见英文名称。截图和自动测试不能替代您电脑上的实际体验。

## 1. 软件是什么

这是本地漫画 OCR、翻译、擦除和排版工具。您保留原始素材，在项目中管理页面、文字框、译文和样式，再导出成品。

- 人工（Manual）：不使用翻译服务，无需 API Key。
- 本地模型（Local）：文本请求发到您配置的本机服务；需要您安装并启动服务。
- 云端（Cloud）：所选 OCR 文本与启用的上下文发送给您选择的第三方 API。

**您会看到：** 启动页与最近项目。**下一步：** 解压便携包，先用几张测试图片走完整流程。

## 2. 下载与解压

1. 从项目 GitHub 的 Releases 页面下载 Windows ZIP 和同名 SHA256 文件。
2. 在资源管理器右键 ZIP → 全部提取，选可写目录。
3. 解压后应有 LinksMangaWorkspace.exe、runtime/、使用说明和许可。
4. 不要在 ZIP 内直接运行，不要只复制 EXE，不要删除 runtime/。

**您会看到：** 一整个应用文件夹。**下一步：** 双击 EXE。此版本未签名；若 Windows 提示未知发布者，先确认下载来源和校验值。

## 3. 第一次打开与项目

1. 启动后选新建项目（New Project），填写名称和保存目录。中文名称可用。
2. Copy Into Project：复制素材，便于移动项目；需要更多磁盘空间。
3. Reference Original Files：只引用原路径，适合大文件；请保留外部素材。
4. 已有项目用打开项目（Open Project）选择整个 .lmw 文件夹，也可从最近项目打开。

**您会看到：** 左侧页面列表、中央画布、右侧属性，底部任务区。**下一步：** 导入素材。

核心编辑写入 SQLite；译文输入在短暂停顿或切换文字框时提交。关闭前等待任务结束。升级前复制整个 .lmw 文件夹，引用项目还需备份原始文件。不要只备份 project.sqlite3。

## 4. 导入 PDF

1. 从导入工具的下拉菜单选 PDF，或把 PDF 拖到窗口。
2. 没有项目时，使用启动页的 PDF 入口，按提示创建项目。
3. 确认导入清单与范围，等待任务完成。
4. 左侧出现页面后点击一页，等待当前页渲染。

**您会看到：** PDF 页面作为独立项目页面。**下一步：** 检查页序并识别 OCR。PDF 导入不代表提供成品 PDF 导出。

## 5. 导入图片与文件夹

1. 点击导入图片或导入文件夹；也可拖入图片/文件夹。
2. 检查文件清单和项目目标，再确认。
3. 空目录、重复文件、损坏图片按提示处理，不要反复点击确认。
4. 左侧选页，使用上一页/下一页、适应窗口（Fit）、100%。
5. 放大后使用抓手拖动查看细节。

**您会看到：** 缩略图逐步出现，当前页显示在画布。**下一步：** 选择页、批次或全项目范围。引用文件移动后按 Missing Source/重新定位提示找到正确原文件，不要删除页面记录。

## 6. OCR

1. 选择当前页或需要的范围。
2. 从 OCR 工具运行识别。
3. 在底部任务区查看进度；不要同时重复启动同一范围。
4. 打开 OCR 文本列表，逐框校对漏字、错字和阅读顺序。
5. 有重要译文时，重跑 OCR 前先备份。

**您会看到：** 画布文字框、列表原文与置信度。**下一步：** 校对后输入译文。核心 OCR 使用随包本地 CPU 模型，不需要翻译 API。竖排、手写和拟声词尤其需要人工检查。

## 7. 人工翻译

1. 选择画布文字框或 OCR 列表行。
2. 在右侧译文区域输入文字。
3. 短暂停顿或切换文字框，确认内容保留。
4. 也可使用文字工具或双击原框直接编辑。

**您会看到：** 同一文字框保留原文与译文。**下一步：** 擦除并回填。人工编辑默认受保护，不会被批量 AI 翻译直接覆盖。

## 8. 可选云端 API 翻译

1. 打开翻译中心 → 翻译服务 → 添加服务。
2. 选择云端 OpenAI-compatible，填写名称、服务地址、模型 ID。
3. 地址通常到 /v1，不要附加 /chat/completions。
4. **由您自己填写 API Key；不要发给开发者或贴入日志。**
5. 按检测/刷新模型确认配置，再选少量文字测试。
6. 检查服务费用、配额和其隐私规则后扩大范围。

**您会看到：** 服务状态与任务预览，检测不会假装已连接。**下一步：** 开始任务并审核草稿。当前协议不是所有厂商专用 API 的通用入口。Key 保存在 Windows 凭据管理器，不写进项目。

## 9. 可选本地模型翻译

1. 自行安装并启动 Ollama、LM Studio 或兼容本地服务，加载您自己的模型。
2. 翻译服务中选择对应类型。
3. Ollama 常见地址：http://localhost:11434；兼容服务常见：http://localhost:1234/v1。
4. 输入实际模型名称，检测/刷新模型后选少量文本测试。
5. 保持外部服务运行，查看其资源占用。

**您会看到：** 已安装模型列表或明确连接失败。**下一步：** 开始任务并检查结果。软件不会安装外部服务、下载 LLM 或扫描您的模型目录。本地配置接受回环地址；远程主机用云端类型。

## 10. 术语库与人物

1. 从翻译入口打开术语库。
2. 添加原文、固定译名、分类和备注。
3. 人物页填写名字、称呼与人物备注。
4. 搜索或筛选检查已有记录，处理冲突。
5. 批量导入/导出 CSV 时保留指定字段，先试少量记录。

**您会看到：** 项目自己的术语和人物列表。**下一步：** 翻译预览中启用需要的术语/人物上下文。CSV 字段为 source,target,category,note；分类值见 AI_TRANSLATION.md（源码 docs/ 下）。关闭前保存正在编辑的行。

## 11. 翻译中心

1. 翻译任务页选择当前框、页、所选页、批次或项目范围。
2. 确认目标语言、服务、模型、保护规则与上下文。
3. 开始后查看进度。暂停会停止后续请求，正在进行的请求可能仍完成。
4. 历史任务先显示最近 100 条；点加载更早任务继续查看。
5. 任务详情查看失败原因，恢复或重试适用的任务。
6. 回到漫画页，审核草稿；缺失 token 信息显示未知，不是零。

**您会看到：** 当前任务与历史状态。**下一步：** 审核译文后擦除/回填。取消、暂停、重试的具体可用状态以按钮为准。程序重新打开时，中断任务不会伪装已完成。

## 12. 擦除

1. 选择文字框，核实范围。
2. 用擦除入口处理当前框、所选框或当前页全部 OCR 框。
3. 复杂背景先试一个框；必要时用蒙版编辑。
4. 擦除有误，立即撤销。

**您会看到：** 框内原文被清理，文字框仍存在。**下一步：** 在同一框回填译文。擦除不删除 Text UID、译文或样式，也不会改写原始文件。

## 13. 回填译文

1. 为选中框输入非空译文。
2. 点击右侧擦除并回填译文，或使用回填入口。
3. 在原框位置检查结果，放大看边缘与背景。
4. 译文需要改时，重新选框编辑并更新回填。

**您会看到：** 译文在原区域排版。**下一步：** 调整字体和 Auto Fit。空译文不会为了回填先擦掉内容。一次组合操作可使用撤销恢复。

## 14. 字体与样式

1. 选中文字框，选择 speech/narration/thought/sfx/note 等项目样式。
2. 字体浏览器选择本机安装的字体，预览后确认。
3. 项目样式统一管理角色；框级覆盖仅影响当前框。
4. 缺失字体提示时选择替换；自行确认字体使用许可。

**您会看到：** 预览和排版变化。**下一步：** 检查字号、边距和溢出。相似字体建议是视觉匹配，不保证找回漫画原字体。软件不分发您电脑上的字体。

## 15. Auto Fit

1. 打开排版属性，启用/运行 Auto Fit。
2. 设置合理的最小/最大字号、边距和行距。
3. 检查横排/竖排、对齐和中文标点。
4. 出现 overflow 时缩短译文、扩大框或调整样式，不要只无限缩小字号。

**您会看到：** fit、warning 或 overflow。**下一步：** 放大逐框看成品，运行质量检查。极长文本或复杂竖排仍可能需要手工调整。

## 16. Quality Check

1. 从项目/质量检查入口显式启动。
2. 选择范围并等待扫描；大项目需要时间。
3. 双击问题定位页面和文字框。
4. 修改缺失译文、未校对 OCR、字体或溢出问题，再检查。

**您会看到：** 问题列表或无问题提示。**下一步：** 导出。质量检查不自动修改项目，也不保证漫画视觉质量已经合格。

## 17. 导出成品

1. 打开导出，选择当前页/批次/项目等可用范围。
2. 选择对话框实际提供的 PNG/JPEG/WEBP 或归档选项。
3. 指定独立输出目录，不覆盖原始素材。
4. 等待底部任务/导出状态完成，打开目录逐页抽查。

**您会看到：** 输出文件与明确任务结果。**下一步：** 检查页数、页序、回填和清晰度，再分享。软件不添加作者/应用水印；素材版权由您处理。

## 18. Word 工作流与原文导出

1. 导出原文，选择当前页、批次或项目，选 DOCX/TSV。
2. Word 中只编辑译文/备注，保留编号、协议字段与文档结构。
3. 不要手工换 Text UID 或只复制某列到新文档。
4. 回导原文档，在预览中确认匹配和冲突，再应用。
5. 回到项目抽查，再回填/导出。

**您会看到：** 原文、译文与备注按稳定 ID 对应。**下一步：** 校对回导内容。协议使用内部标记，不依赖中文标题；重复、未知 ID 应按预览处理。

## 19. Undo / Redo 与恢复

1. 编辑后用 Ctrl+Z 撤销，Ctrl+Shift+Z 重做，或从编辑菜单操作。
2. 看操作名称与画布结果；不是每个外部文件动作都可撤销。
3. 任务中断后查看任务状态，按支持的继续/重试入口处理。
4. 升级与大批量操作前复制完整项目；回退时使用对应版本与完整备份。

**您会看到：** 支持的编辑恢复到前后状态。**下一步：** 确认内容正确再继续。不要手工修改 SQLite 或删除原始 OCR 记录来尝试修复。

## 20. 常见问题

| 问题 | 先做什么 | 下一步 |
|---|---|---|
| OCR 没结果 | 确认页面加载、范围、模型状态和任务错误 | 试清晰的小图；复杂文字人工校对，查看日志 |
| 本地模型连接失败 | 启动外部服务、加载模型，核对 localhost 地址和端口 | 检测服务后重试小范围，检查外部服务日志 |
| API 401 | 核对自己输入的 Key、地址与账号权限 | 更新配置再检测；不要公开 Key |
| API 429 | 降低并发，确认余额/限额与服务方等待要求 | 等待后重试失败任务；避免连续重复启动 |
| 字体缺失 | 安装合适且获许可的字体，重新选择/替换 | 检查项目样式和框级覆盖 |
| 文字溢出 | 缩短译文、扩大框、调边距/行距/字号范围 | 重新 Auto Fit 后视觉检查 |
| 项目打不开 | 确认选整个 .lmw、文件可写、磁盘空间足够 | 先复制项目；查看错误和日志，不重建空库覆盖旧项目 |
| 引用图丢失 | 找回原文件，使用重新定位 | 保留外部素材备份，核对正确图片 |
| 如何找日志 | 帮助 → Diagnostics/环境信息 → Open Log Folder | 附应用版本与复现步骤；分享前删除隐私路径/文本 |
| 任务像卡住 | 看底部任务、当前请求与日志 | 大图/OCR/外部模型需时间；先暂停，等待当前请求结束 |

真实付费 API、真实本地模型、系统 DPI 与可见 Windows 操作在本次自动准备中均为 **NOT TESTED**。请按最终用户验收表在您电脑上逐项记录。
