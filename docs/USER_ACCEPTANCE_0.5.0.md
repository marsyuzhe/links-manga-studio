# Links Manga Studio 0.5.0 人工验收

以下操作由用户在真实 Windows 窗口执行。自动化仅覆盖 Qt offscreen、单元测试与打包运行，不代表真实屏幕已验收。每项请记录 PASS / FAIL、DPI、系统版本与截图。建议先复制一份旧项目进行兼容测试。

1. **Startup**：打开 EXE，检查标题、拖放区、打开 PDF 主按钮、新建/打开项目以及最近项目。通过最近项目的菜单执行打开、打开所在文件夹和移除。
2. **Dark Theme**：检查启动页、菜单、工具栏、页面列表、画布、检查器、底部面板、字体浏览器、设置、对话框和提示文字的对比度。
3. **Light Theme**：切换浅色并重复检查上述区域；关闭和重启后确认主题保留。
4. **System Theme**：切换跟随系统，关闭并重启，确认启动时采用当前 Windows 应用主题；实时跟随系统切换不在本版承诺范围内。
5. **Drag PDF**：把 PDF 拖入启动页，确认自动创建项目、按需显示页面、缩略图与画布可用。
6. **Old Project**：打开 0.4.x `.lmw` 副本，核对页数、Page UID、Text UID、OCR、译文、字体和项目样式；确认主题选择没有写入项目数据。
7. **OCR**：运行当前页 OCR，检查进度、原始文字与文本框。
8. **Translation**：选择文本框，编辑译文，切页再返回，确认内容持久化。
9. **Font Browser**：搜索、预览、收藏、最近使用字体，并检查缺失字体提示与替换。
10. **Similar Font Recommendation**：查看定性的相似字体推荐，确认显示高/中/低等级，不出现虚假精确百分比。
11. **Project Font Style**：修改项目“对白”字体，检查继承框同步更新，局部覆盖保留。
12. **Auto Fit**：测试窄框、长译文、中文标点、最小字号与溢出提示；不要出现无限缩小。
13. **Erase & Refill**：擦除并回填译文，检查 Text UID 不变、原框可再次编辑，导出图不带产品或作者水印。
14. **Undo / Redo**：检查译文、擦除并回填、文字框移动与项目样式修改的动态动作名及撤销/重做结果。
15. **Quality Check**：确认未翻译、低置信度、未回填、溢出、字体、越界、未导出等问题可从列表定位页面与文本框。
16. **Simple Mode**：确认 UID、BBox 等内部字段隐藏，默认显示译文与简洁适配提示。
17. **Advanced Mode**：确认内部字段与排版参数可见，主题切换后保持当前模式。
18. **About**：核对 Links Manga Studio、Version 0.5.0、Created by Links Tam、诊断复制与日志入口。
19. **Export**：导出 PNG/JPEG/WEBP、DOCX，核对图片无品牌水印、Word 稳定字段协议及翻译回导。

记录机器 DPI 缩放（例如 100% / 125% / 150%）、屏幕尺寸和检查日期。未实际执行的项目标记 **NOT TESTED**。
